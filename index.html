    Build blocks

    Block length is also the length of every new phase you add. If the session does not divide evenly, the last block is shorter.

    Sound and timing

    Set heads-up to 0 to turn it off. If music plays from the same device, set the system volume first, then balance with this slider.

    Voices come from your browser, not from this page. The most natural ones are the voices named Natural in Microsoft Edge on a computer, then the Google voices in Chrome. Both need an internet connection; if that fails, the timer switches to an offline voice for the rest of the session. Safari, and every browser on iPhone, can only use the built-in system voices.

    Manage routines

    While the timer is open: Space pauses, the left and right arrows skip, minus and plus change the current phase by 30 seconds, F toggles full screen, Esc goes back to the plan.
